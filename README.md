# SigmaOS adaware

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-adaware`.

No malware detection, antivirus scanning, threat intelligence, or other security enforcement is implemented in the current source. Do not rely on this crate as a security control.

## Build

```sh
cargo check --lib
```
